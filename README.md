# Songs of Praises — Static Hymnal Data

Public static JSON dataset (`hymns.json` + `version.json`) for **Songs of Praises — Hymn Modernizer** offline-first silent background sync.

- `version.json` — current catalog version, SHA-256 hash, hymn count, and timestamp.
- `hymns.json` — validated hymnal catalog (classic lyrics, modern English, author stories, anchor scriptures, tune metadata).
